## 3. 云端新增发现及其影响

### G1：JSON 摘要不能信任自填字段，更不能遇到 raw 不符就改口径

`digest_row` 在声明为 raw_sha256 的比对失败后，读取 JSON 自带 canonical_digest，只要字段等于预期就写 byte_match。它没有重新计算 JSON 正文 canonical，也没有由外部合同预先决定口径。云端用修改正文、保留旧摘要字段的 JSON 实际复现了错误放行。

`selection_digest` 本来使用 canonical 并无问题，问题在校验实现。两份公开 selection 正文经云端重算均有效，因此这里**没有证实实际选型文件被改坏**。尚需把本地实际消费文件的 raw/canonical 身份和公开已核副本对应上，并披露 81 项明细的真实口径。

### G2—G5：整体 passed 字段遗漏必要子检查

G2：`audit_ot1` 最终判定检查 violations 和 compared，却没有要求 only_left_finite/only_right_finite 均为零；一个重建缺失格可以漏过。G3：`audit_ot2` 计算了 recomputed_vs_stored，但最终 passed 不消费它；即使存盘状态与重算不符，也可以通过。G4：P6.1 的 evaluation 数组为空时直接通过，即使推断行里存在成熟标签。G5：DataHub 缺失返回 blocked_missing_dependency，B 总判定只排除 failed，可能把来源未查与数组检查合并为 passed。

这些漏洞应修正，但本次已上传摘要中，C 的双向有限差异为零、D 的存盘比较为零、B 的 evaluation 非空且原始采样已报告完成。因此**漏洞不等于这次真实数值观察已经被推翻**。优先重判已有完整报告并加反例，不要求为测试门漏洞重新物化数据。

### S1：K1 真正消费的分支没有被 D/E 覆盖

`IntradayK1InputStore.assemble_inputs` 明确按 `symbol_position % 5 + 1` 取 state_values/state_available，拼入 stock_factor_exposures、exposure_reliability、exposure_available，形成 71 维特征。其源码 blob 为 `6942fb2dc20d24307578bc7dda45368afaf3d1f5`。

本地 D 只重建 full_reference；E_bind 只比较 epsilon 与轴。故“epsilon 吃的就是 OT1”是成立范围明确的报告，**不能用来关闭实际 cross-fit 状态、暴露、掩码与 K1 特征装配的来源链**。这是原任务书 D/E 已要求的直接消费检查，不是新增一个无关关卡。

### S2：工具固定后的因果，不等于选型过程的历史因果

选型记录包含 2009—2020 年结果，源码 evaluate_annual_tools 消费未来因子收益。即使固定工具输出满足前缀稳定，也不能宣称这些工具在 2017 review 或更早时刻已经按当时信息选好。`fresh_oos=false` 正确标识已消费材料，但不会消除事后工具选择对历史模型特征/分数证据身份的影响。

旧状态、checkpoint 和分数可以保留用于冻结复现和已消费开发分析；这不自动要求重训。若要提出历史时点可实施、因果回测或独立预测验证主张，则需按该评价截止点有合法身份的选型，或者另作恰当的前向/嵌套设计。本轮不授权启动该研究，只修正“均可复用”的用途范围。

### S3：分钟标签、事件时间与到达时间应分开

“无13:00、有13:01及15:00”是端标签的样本线索，不是完整供应商/转换器时间合同。样本时间戳还带 Z；仅截字符串并按上海墙钟解释，需要转换链依据，不能只从交易时段数字推出。

即使端标签假设成立，标为14:31的bar其open发生在这根bar起始附近，而不是14:31标签时刻；它未必严格晚于读取14:30 close、完成计算及送单的时点。当前结果可以保留为原取价代理重现，不将分钟标签先后升级为成交可得性。available_at 的入库日期也不提供历史发布证明。缺少这些证据时保留未验证，不强制新增全湖或逐笔行情任务。

### S4：lineage 原字符串属于歧义，不足以判定错用 t-1

`entry_open_t_plus_20_div_entry_open_t_minus_1` 可以被理解为“entry[t+20] 除以 entry[t] 后减1”，也可能被误读为分母取 t-1。没有给出解析器按后一种方式消费它的证据。因此本次将“明确公式不一致”收敛为**说明字符串可读性/歧义问题**。算术源码与本地重算公式一致。后继说明写成 `(entry_open[t+20] / entry_open[t]) - 1` 即可；不改原 lineage 摘要、不重算数组。
