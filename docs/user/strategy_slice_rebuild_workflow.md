# 策略自然年研究会话—整案重建工作流

## 它解决什么

过去的常见失败有三种：长历史会让强时期遮住弱时期；把历史切得过密，会把相关症状误当成硬约束；把并行实验误写成 V5→V6→V7 的继承链，又会让后来的实验直接抄用前一实验的答案。当前工作流改为十二个自然年研究会话：每年先盲测上一快照，再开放归因，并从共同起点与本支线累计材料重建一份完整新快照。

这是项目级强制方法。开始任何策略新建、调参、路由、组合、漂移诊断或回测验证前，AI 助手必须先调用 `$strategy-slice-rebuild`。

## 十二个严格研究会话

默认历史图谱使用：

- 2009—2020 共十二个互不重叠自然年；
- 一次研究会话只允许打开一个自然年；
- 不再使用半年错位或其他滚动窗口；
- 上一会话的证据、分析台账和链式回执未封口，下一会话不得开始。
- 禁止用 shell 循环或批量驱动器连续完成十二年；每年必须单独调用证据准备器，并由主研究者手写分析和完成约束审查。
- 第一年盲测共同起点；第二年起只盲测上一年封存的新快照。
- 每年都必须完成整案重建，不允许把上一年胜者当代码父类再补一条规则。

脚本可以按统一口径准备某一年的数字和图形索引，但不能批量写结论。每年都必须由主研究者独立完成问题归因、约束审查和台账；子代理只能提供证据，不能替代主研究者签署科学结论。

“整案重建”不等于禁止加一层。入场时一次性决定并冻结到退出的否决门、同工具二选一路由，本身可以是一套低自由度完整候选。它仍需放回完整账户逐年计价：当前默认至少改变 3 个年份、有效年份中至少 60% 获得正增量、有效年份中位增量不为负且总增量为正。只改善一个年份、靠总体合并收益遮住其他年份退化的候选必须拒绝；通过者也只能冻结为回溯研究候选，不能冒充新鲜验证或生产版本。

上述60%与分布规则现在只控制“候选晋升”，不再删除弱但真实的进步。候选先通过金融、数学、时序、完整账户、确定性、source closure、多重尝试和权限硬门；之后只要在结果前冻结的主目标上、相同账户/成本/比较器口径下改善超过数值重放容差，就必须写入 progression ledger。它可以因分布弱、贡献集中、风险权衡或跨时钟冲突而不晋升，但不能被改写成“没有任何进步”。详见[渐进开发工作流](strategy_progressive_development_workflow.md)与[白皮书](../ops/strategy_progressive_development_whitepaper.md)。

## 执行顺序

1. **封印数据角色。** 写清开发素材、已消费复审、新鲜挑战和聚合黑箱的边界。
2. **声明版本关系。** 明确哪些是继承版本、哪些是从同一共同起点分叉的并行实验。
3. **冻结隔离清单。** 并行实验只允许共同起点、原始数据、通用工具和本支线材料；其他并行实验的策略、参数、台账、结果和结论全部禁读。
4. **冻结执行考卷。** 固定执行价、T+1、成本、指标和本轮搜索预算。
5. **建立年度会话图谱。** 只列十二个自然年，日历身份不得进入交易公式。
6. **盲测旧快照。** 当前年份先只跑已冻结策略，不排名新候选、不改公式。
7. **逐图逐事件开放归因。** 每年记录机会、账户、责任边际、漏涨、吃跌、错向与打脸；不受旧候选轴限制。
8. **同根并案。** 跨年重复症状归并为可证伪根因；原始负值和未解决根因没有硬否决权。
9. **预登记本轮整案族。** 看完问题后先写本轮有界候选族、自由度与搜索次数，再执行比较。
10. **从共同起点整案重建。** 使用截至当年的本支线累计材料，完整重价真实 T+1 和成本；严禁增量补丁继承。
11. **封存新快照。** 公式摘要、策略 digest、材料清单、尝试次数和回执全部冻结后，下一年才可开启。封存时的源码摘要属于历史证据：后续工作流升级后，应从当前文件或 Git 历史中的精确旧 blob 证明它，禁止把旧摘要重绑为今天的源码。
12. **拒绝假后继。** 共同起点只做比较；若只剩账户等价方案，报告 `no_incremental_successor`。
13. **正确标注终态。** 2020 年材料参与构建的最终快照尚未经历新年份挑战，只能叫“等待新鲜期的研究候选”。
14. **完成训练后账户审计。** 模型/分数冻结后，按 A0—A7 单独冻结并测试 TopN、权重、不可交易、成本、集中度和时钟；旧政策盲测与完整候选族重价必须是两个命令，账户结果不得回流续训。

## 失败如何回流

| 卡点 | 科学含义 | 返回位置 |
|---|---|---|
| 年度会话未完成 | 当前年份尚未被认真处理 | 补完本年台账，禁止打开下一年 |
| 读取并行实验成果 | 当前支线已被污染 | 整条支线作废，从共同起点重新开始 |
| 根因或证据不完整 | 症状尚无否决权 | 回到归因，换测量/因子族 |
| 未晋级诊断量被写成入场硬门 | 考卷把观测误当机制 | 本轮按原考卷封账；下一轮移除硬门，诊断量只参与排序和解释 |
| 硬义务超过候选族自由度 | 当前候选族无法表达已知机制 | 回到候选族设计，不堆硬门 |
| 只剩基准或账户等价方案 | 没找到增量解 | 报告无增量后继，不发布新版本 |
| 上一快照在下一年失败 | 完整假设被新材料证伪 | 把该年转为素材，从共同起点整案重建；禁止补丁修旧快照 |
| 新期间没有可反证机会 | 证据不足 | 保持冻结，等待新机会，不宣称通过 |

## 当前隔离实验数据红线

当前支线只允许读取 `2009-01-01 <= t < 2021-01-01`。V5、V6、旧 V7 与当前支线是从 V4 共同起点分出的并行实验；它们相互之间不能参考策略、候选、参数、台账、结果和结论。`2021—2026` 已被旧实验消费，既不能打开细节，也不能用已知聚合结果为当前支线排名。
