## 当前定位

FactorLab 当前基线是 **API-first**。Headless CLI 是同一套 API / domain 逻辑的正式包装，不是第二套业务系统。

本仓仍处于**后端化转换期**：FactorLab 负责后端数据、研究、治理与 ResultPackage，前端产品和交互边界以 Baylum 项目外壳为准。
一级策略入口继续使用正式名称 **Residual Risk-Off 风险防护策略**，避免与普通风险因子或研究工具混淆。

策略是策略，工具是工具。因子库、挖因子、模型训练、Research Runner、脚本、schema 和测试是工具或基础设施；只有被治理链升格并由证据支持的 strategy result / manifest / account opportunity 才是策略结果。

因子是策略输入，不是默认的新策略本体。有效因子、宏观状态、模型筛选列或挖掘表达式的默认用途是纳入既有策略 / 上一版本策略做 `Vn` vs `Vn + candidate` 增量 ablation；除非用户明确授权新策略族，不得用 standalone 因子模型是否打败上一版策略作为保留、丢弃或替代依据。
