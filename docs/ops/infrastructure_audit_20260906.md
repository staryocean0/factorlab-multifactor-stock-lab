## 保留的必要约束

时点可得、标签成熟、收益/复权/股票支持一致、预测证据身份、分解守恒、实跑状态诚实、历史原字节保留及无生产授权。这些防止明确错误；不规定结果必须为正、残差必须非零、必须使用某模型或逐级K，也不规定所有阶段线性通关。

## 不同身份的文件如何演进

`CURRENT.json` 是唯一路由；manifest描述现行角色，不记录全仓每个活动文档的固定摘要。状态随着新证据正常更新，不要求为进度变化发布新数学合同。工作流负责动作，白皮书负责定义，旧合同与旧输出保留历史身份。实证运行仍记录确切代码、输入、模型和输出身份；没有放松历史复现要求。

旧 V1.3 合同单元测试以固定 Git 修订还原旧字节。新的 V1.4 检查与反例作用于实际工作树。不能拿历史基线测试通过替代当前实现测试。新增历史模块若缺依赖会在 `test_scope.json` 明列；恢复依赖后自动进入执行，失败不会被忽略。

旧 `package_scope.json` 中模型运行权限是原交付快照记录，不覆盖当前任务工作流。数据用途和不准重新分发论文的约束仍保留。仓库公开性与该声明之间的冲突需所有者处理；本轮未擅自修改可见性、删除历史或重写仓库历史。
