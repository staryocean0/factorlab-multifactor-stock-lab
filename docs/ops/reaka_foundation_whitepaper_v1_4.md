# REAKA 金融对象、数学机制与研究证据：白皮书 V1.4

当前路由：[CURRENT.json](../../CURRENT.json)。本文解释对象和方法；操作见 [任务工作流](../user/reaka_multifactor_current_workflow_v1_4.md)，进度见 [研究状态](research_state.json)，稳定断言见 [语义@1.2](reaka_foundation_semantics@1.2.json)。本文承接 [V1.3 推导与审计](reaka_foundation_whitepaper_v1_3.md)，本轮没有重读授权论文全文或重新实证验证其结论。

## 1. 金融需求先于工具

目标是以自研市场、大小盘、行业及后续个股信息，改善 A 股横截面选股。既有产品是满仓主动多头，允许主动规模和行业暴露。风险中性化可以作为识别机制的对照，不自动变为产品约束。

市场条件本身可以相同，但若给所有股票分数只加同一常数，排序不会改变。候选方法应说明如何通过异质 beta、行业交互或个股相对响应影响横截面差异。广播到很多股票的一个宏观状态，不增加同等数量的独立市场观测。

采用 REAKA 架构是有条件的建模选择，不是盈利保证。自研因子可以成为输入；改目标、特征或训练协议后不能直接继承论文实验结论。方法预分析必须包含适用前提、可反驳例和最简单基准，不要求唯一算法。

## 2. 必须先声明预测的是哪个对象

总收益、金融收益残差、潜空间动力残差和账户归因不是同一个目标。现任身份见状态文件：其 `r0` 表示未启用潜动力残差修正网络，**不是未使用金融残差**。已交付 fit-prefix 实现用历史 `epsilon` 序列拟合，`epsilon_future` 用于 review；这仍不证明上游 epsilon 的 PIT 构造正确。

改为预测总收益或改变残差分解时，应说明新目标及最终排序/收益重建。不能悄悄换字段而沿用旧指标。单看残差预测较准，也不能推出总收益排序更好，需验证实际消费方式。

## 3. 编码、gate、状态和算子

设收益历史编码为 Hy、特征历史编码为 Hx：

\[
G=\sigma(\operatorname{GateNet}(H^x)),\qquad
Z=H^y\odot G+H^x\odot(1-G).
\]

G 增大时收益编码占比增加。G 不是市场、规模、行业的金融配置权重。可观测条件 S_obs 是决策时已知的上下文，不是潜状态 Z，也不是 operator 的天然监督标签。

训练中的 soft/Gumbel 混合与正式预测 hard selector 分开：

\[
\widehat Z^+=\sum_j\pi_jK_jZ\quad(\text{训练}),\qquad
s=\arg\max_j a_j,\quad\widehat Z^+=K_sZ\quad(\text{正式推理}).
\]

argmax 产生索引，必须查出对应矩阵。矩阵作用方向须与实际实现一致，不能用整数索引参与矩阵乘法。

| 容易混淆的量 | 正确含义 |
|---|---|
| K_j | 学习到的潜空间转移矩阵，不是第 j 个金融因子 |
| N_candidate | 实例化模型配置的矩阵个数；训练不会自动增删 |
| N_used | 已声明支持/占用规则下实际使用数，不等于机制已经识别 |
| N_selected | 独立比较研究选择的容量，不是 selector 自动给出的真值 |
| TopK | 组合持股数，不能与上述数量建立等式 |

需要容量选择时可以比较多个候选，但必须明示训练与选择的区别。旧描述性 Stage3 没有选容量资格，不等于禁止后续独立容量研究。K2 失败不推出 K3 必失败；K-only 无增益也不推出 K+R 无效。逐级 K 后残差与论文联合训练是不同协议，均需各自证据，没有被本文强制选用。

## 4. 三种残差及其适用条件

金融收益残差在同一收益区间、单位、复权和股票支持上定义：

\[
\epsilon^{return}_{i,[u,v]}=r_{i,[u,v]}-\alpha_{i,t}
-\beta^M_{i,t}F^M_{[u,v]}-\beta^S_{i,t}F^S_{[u,v]}
-\boldsymbol\beta^{I\top}_{i,t}\boldsymbol F^I_{[u,v]},\quad t\le u.
\]

系数及估计所需信息必须在预测时已知，股票和因子区间收益成熟后才能计算该实现残差。冻结时刻与标签成熟时刻是实际时间，不是列名。截距约定、拟合窗、cross-fit、联合/顺序残差化、缺失、行业约束与基底生成均应和实现相符；顺序残差化通常依赖顺序。样本内正交不证明后续区间仍正交，也不证明残差是个股 alpha。

潜动力残差是另一空间中的量：

\[
R^{latent}=Z^+-K_sZ,\qquad
\widehat y=D(K_sZ+\widehat R^{latent}).
\]

训练可以利用成熟训练目标，正式预测的修正只能使用决策时信息。同一金融残差序列也可作为收益编码目标，而同时令潜动力修正网络关闭；这正是 `r0` 不等于“无金融残差”的原因。

账户 account_other 依赖账本分解，可能包含费用、现金或归因余项；不能直接当作残差网络 alpha 标签。分解为证明守恒而保留余项，不等于必须预测它。零残差、不可预测残差、非零波动但零条件均值和无经济增量都是合法结果。

## 5. 可辨识性与残差评价

可逆坐标变换 Z'=AZ、K'_j=AK_jA^-1，加上相应 decoder 变换，可以保持预测不变；算子标签也能置换。因此独立模型的原始矩阵距离、潜能量或编号差异不能单独证明金融机制。应在共同观测支持上比较作用、解码输出、覆盖和跨折稳定，金融解释另作检验。

MSE 训练的 MLP 评价条件均值；DDPM 评价条件分布。若 E[R|I_t]=0，均值模型输出零可能正确，而分布样本仍有非零能量；不能用同一幅度门要求二者。DDPM 需要历史信息下完整采样与适用的校准/分布评分，不是 noisy(true residual) 的一步去噪。teacher-forced 去噪是训练诊断，不是正式预测证据。

非线性 decoder 下，为估计收益条件均值应逐样本解码再平均，而不是默认先平均潜残差再解码等价。占用率、能量比等诊断的阈值需匹配任务，不能升级为普适盈利定理。

## 6. 数据时钟与评价单位

特征、收益历史、股票池、行业归属、市值、缩放和缺失处理必须在决策时可得。14:30/14:45 不可使用当日收盘以后才有的信息；日线不是相应时刻成交价的替代证明。QFQ 信号价不能直接当 raw/PIT 成交价。未来 H 日标签要到区间终点及发布延迟之后成熟；把日期移到昨天不能令未成熟目标变成历史。

序列的一步潜转移、训练步长、最终收益期限和持仓区间必须对应。重叠目标的切分与 purge/隔离要依据实际端点。参数只能从所允许的训练资料估计，不能让未来标签决定推断支持。

旧 Stage4 是前月条件与后月既定持仓已实现贡献的关联，不是未来预测 IC。其重复月份及组件覆盖问题需沿来源解决，不能任意 drop_duplicates 或按结果挑行。月度状态被复制给多只股票，或两个相近时钟给出相似结果，都不能当成独立重复样本。

数据范围与消费状态继续按 [用途声明](../governance/data_usage_declaration.json) 执行。补件不重置 OOS；本轮不扩展到未授权年份。

## 8. 证据能支持多大的结论

原字节一致证明交付身份，结构检查证明所查结构；都不自动证明 PIT 或真实拟合过程复现。历史拟合声明、checkpoint 实体、冻结分数和实际重算应分别说明。消费端应独立绑定预期任务与模型身份，不能让结果证书自行定义自己的预期身份。

合成反例支持实现性质，不支持市场盈利；真实预测比较需同目标、同信息、同日期/股票支持并考虑依赖与尝试分母。账户经济结果还需成交、费用和归因守恒。CI 成功、哈希一致、模型健康或曾经的 passed 字段均不授予金融签字、基线晋级或生产权限。

本轮优化的是研究基础设施和接手指导，不产生新的策略效力结论。当前证据局限由状态文件维护，不再写成所有未来研究永远关闭的数学条款。
