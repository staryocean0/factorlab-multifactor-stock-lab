# REAKA P6.4.1 双时钟同配置归因与数学门校准白皮书

## 问题

P6.4中14:30选中`d8-h8 / LR 0.1 / 4周期`，14:45选中`d16-h16 / LR 0.03 / 3周期`。
因此旧结果同时改变了决策时钟、模型容量、LR和覆盖周期，不是单独的“15分钟实验”。
本步用固定2×2配对分离时钟效应、配置效应和交互效应。

## 数学语义审计

当前 `ReakaPaperModel.forecast()` 对完整窗口只调用一次 `_transition`，最终分数是该一步
K映射后解码序列的末点。它没有把K在未来连续递归2、4或更多步。因此：

- 谱半径是重复递归K时的渐近稳定性量；
- 它可用于未来recursive rollout或长时间动力学身份的硬门；
- 对当前单步H20金融分数，不应单独一票否决，必须同时看观测一步放大、一步latent误差和金融分数扰动。

本步对每个seed报告谱半径、条件数、观测一步gain、latent relative MSE，以及
`K^1/K^2/K^4`在观测latent上的gain分位数。递归结果只用来解释旧谱半径门，不会被回填成新选参分数。

## 金融对象和扰动门

当前财务评分对象是三种子每日rank-z后等权集成，不是任何一个seed单独上线。
因此成员删除和输入噪声的金融硬门应对集成score施加；单seed结果保留为数值分布和异常定位。

基础设施校准不改变以下硬门：非有限loss/梯度/参数必须拒绝；条件数仍受
`condition * eps_float32 <= 1e-3`约束；当未来真的使用recursive rollout时，必须重开谱半径硬门。

## 归因输出

每个连续指标按饱和2×2分解报告：

- clock effect：两配置下14:45减14:30的平均；
- config effect：两时钟下B减A的平均；
- interaction：`(1445_B-1445_A) - (1430_B-1430_A)`。

三者都保留连续值和绝对占比，不用某一格的“成功/失败”代替机制归因。

P6.4.1只能校准当前数学门与金融对象的对齐，不授予P6.5、残差、账户或生产权。
