# REAKA 多因子选股基础设施现行白皮书 V1.3

本白皮书解释本私有研究仓库的现行数学与金融口径。唯一现行清单为 [current manifest@1.3](reaka_multifactor_current_manifest@1.3.json)，机器语义合同为 [foundation semantics@1.1](reaka_foundation_semantics@1.1.json)，执行顺序见 [工作流 V1.3](../user/reaka_multifactor_current_workflow_v1_3.md)。旧版本保留为冻结历史材料；其“当前”“唯一动作”“已通过”等措辞不再授予本仓库执行权限。

本轮目标是五位一体基础设施一致：文档、白皮书、代码、测试和工作流使用相同对象、时钟与证据边界。它不等于确认历史数据已齐、不等于验收旧 Stage4 结论，也不等于证明策略具有正收益。当前只进行基础设施审计、修复和合成验证；用户通知数据补齐后，才开始数据完整性核验。历史 Stage4 仍因重复月份及组件来源缺口而阻断，训练、残差训练、K 容量选择、账户、用户金融回执及生产晋级均未开放。本清单不修改外部本地 FactorLab 的 current 指针。

## 1. 金融目标及论文的适用边界

本项目希望利用自研市场、大小盘、行业及后续个股信息，在条件变化时改善 A 股横截面选股。既有产品定义是满仓主动多头，允许主动规模及行业暴露；研究中控制暴露，是为了判断预测机制，不自动把产品改为市场、规模或行业中性组合。

REAKA 的编码、潜动力和残差修正框架与这个目标**有条件兼容**。论文不要求输入必须是 Alpha158，自研因子可以输入特征编码器；但替换因子、目标或训练协议后，应称为借鉴论文架构的项目模型，不能继承论文实验结论。论文也不提供“市场、大小盘、行业之后必然剩下可交易个股 alpha”的定理。

如果市场条件只对每只股票的分数加相同常数，横截面排序不变。要影响选股，必须产生股票之间的差异，例如异质市场 beta、行业交互或模型学习的相对响应。广播到多只股票的同一个市场条件，不能当作同样数量的独立市场状态观测。

未来若改为预测金融残差而不是总收益，必须另行声明预测目标和总收益重建方式。不能在实现中默默替换目标，再沿用原有总收益评价结论。

## 2. 条件、潜状态、gate 与算子

以下是概念方程。工程中的样本索引、序列偏移和标签成熟时刻必须同时满足第 5 节，不能把符号上的下一步直接当作任意持有期收益。

\[
H^y=\operatorname{LSTM}_y(y_{\mathrm{history}}),\quad
H^x=\operatorname{LSTM}_x(X_{\mathrm{history}}),\quad
G=\operatorname{sigmoid}(\operatorname{GateNet}(H^x)),
\]
\[
Z=H^y\odot G+H^x\odot(1-G),\qquad
a=\operatorname{SelectorNet}([Z,H^y]).
\]

训练时，Gumbel-Softmax 给出混合系数 \(\pi_i\)，并使用
\(\widehat Z^+=\sum_{i=1}^{N}\pi_iK_iZ\)。正式推理使用
\(s=\arg\max_i a_i\)、\(K_s=\operatorname{Codebook}[s]\)、
\(\widehat Z^+=K_sZ\)。argmax 返回的是索引；必须据此查矩阵，不能把整数索引当矩阵相乘。

| 对象 | 现行含义 | 必须遵守的边界 |
|---|---|---|
| 外部条件 \(S_{obs}\) | 决策时已经可见的上下文，如上一自然月趋势 | 不等于潜状态，也不是 operator 的监督标签 |
| 潜状态 \(Z\) | 收益与特征历史的学习表示 | 不自动等于命名的宏观状态或金融因子 |
| gate \(G\) | 收益编码与特征编码的逐潜维融合比例 | G 增大时收益编码 \(H^y\) 占比增加；不是市场、规模、行业配置权重 |
| \(K_i\) | 学习得到的潜空间转移矩阵 | 不是第 i 个金融因子，也不必对应一个可命名市场状态 |
| \(N_{candidate}\) | 结果前冻结的候选模型矩阵个数，简称配置 N | 不由三类因子数、外部条件类别数或持股数决定；构建后不会因 selector 学习自行增减 |
| \(N_{used}\) | 给定数据与已声明占用规则下，训练后实际使用的算子数 | 只是使用情况，不自动证明可辨识或金融有效 |
| 有效容量支持 | 给定样本、协议与训练结果后获得支持的容量描述 | 不等于配置 N、占用数或永久的真实市场状态总数 |
| \(N_{selected}\) | 通过独立研究选择流程选定的候选容量 | 不等于模型内部自动给出的真值；本轮没有选择权限 |
| 组合 TopK | 持股数量或选取数量 | 与 \(K_i\)、N 没有数量等式 |

“K1、K2”必须标明是在说矩阵 \(K_1,K_2\)，还是在说 N=1、N=2 的容量实验。本项目不要求用户给出真实算子数量；矩阵与归属由模型学习，容量候选预算需在看到相应结果之前冻结。模型训练不自动改变已构造的矩阵数量；使用情况、有效容量支持和最终选择分别由其对应证据及研究流程给出。

上一自然月条件可以作为特征上下文或已声明的条件交互进入。当前第二轮意图是讨论指数、行业通道的条件交互，规模暂不增加该条件交互；这只是候选问题，未被 Stage4 验收。不得根据旧归因表贡献的正负手工规定 gate 方向，不得强制“上涨条件对应 operator 1”。股票级 selector 也不自然等于全市场统一 regime；若未来要求共享市场动力，应显式设计和评价共享结构。

### 可辨识性与容量政策

对可逆矩阵 A，变换 \(Z'=AZ\)、\(K'_i=AK_iA^{-1}\)、\(R'=AR\)，并相应变换 decoder，可以保持股票预测不变。算子标签也可以置换。因此，独立训练模型的原始矩阵距离、潜残差绝对能量或标签编号，不能单独证明金融机制已识别。矩阵只在未被数据占据的方向不同，也不足以证明存在不同的已观测动力。

有效容量应结合共同观测支持上的算子作用、解码输出差异、样本覆盖、跨折稳定和标签对齐评价；金融解释另需有金融对象和反例支持。支持度、占用率和条件数是证据的一部分，不能凭一个通用阈值宣称识别成立。

旧技能第 7b 节和旧 admission 文件中的“逐级 K，停止后再考虑残差”是一个项目搜索政策，不是 REAKA 定理，也不是本轮自动获准执行的工作流。它可作为后续独立预注册协议的候选；若重新采用，需明确停止规则、预算和证据对象。K2 失败不推出 K3 数学上必失败；K-only 无经济增量也不推出 K+R 必然无效。数据泄漏、错时钟或非有限值等基础无效性则不能用后续残差层补偿。论文的端到端联合训练与先选 K 再训练残差应分别命名、登记与比较。

## 3. 三种残差必须分开

### 金融收益残差 epsilon_return

在同一收益单位、复权约定、股票池和时间区间内，定义：

\[
\epsilon^{return}_{i,d}
=r_{i,d}-\alpha_{i,t}
-\beta^M_{i,t}F^M_d
-\beta^S_{i,t}F^S_d
-\boldsymbol\beta^{I\top}_{i,t}\boldsymbol F^I_d,
\qquad t\leq\operatorname{prediction}(d)\leq\operatorname{start}(d).
\]

这里 t 是系数冻结时刻，d 是之后被解释的收益区间。允许冻结与决策或区间起点同刻，但冻结所依赖的标签及输入必须已经可用，不能包含该待预测区间的未来信息。股票收益与因子收益都实现后，才可以计算这段历史残差。系数估计与收益重建必须采用同一个截距约定；现有 OT1 的含截距最小二乘使用上式，不能估计时有截距、重建时却省略。明确声明无截距的模型则取该项为零，不能与含截距模型混用。因子基准、联合或顺序残差化、顺序、行业约束、共线性处理、加权、缺失和可用股票池必须登记；顺序残差化一般受顺序影响。

现有 OT1 的市场、规模、行业顺序基底以及“先前周度系数解释下一有效区间”是具体实现，不是金融分解的唯一正确方式。行业和规模基底本身也须按其声明的历史拟合窗口生成，不能从待解释区间重新拟合。金融残差仍可能包含遗漏共同风险、系数误差、数据误差和噪声；样本内正交不保证后续区间正交，更不证明它就是独立个股 alpha。

### 潜动力残差 residual_latent

\[
R^{latent}=Z^+-K_sZ,\qquad
\widetilde Z^+=K_sZ+\widehat R^{latent},\qquad
\widehat y=\operatorname{Decoder}(\widetilde Z^+).
\]

训练可以接触成熟训练标签并构造真实潜残差。正式推理必须只依赖预测时的信息估计条件均值或采样条件分布。用于正式推理评价的参考残差，应来自同一冻结 checkpoint、相同历史编码和 hard selector 的下一潜状态差；不能把训练 soft selector 的残差直接改名。

金融收益残差与潜动力残差处在不同空间、依赖不同模型，不能直接相加、替换字段或共用一个未经说明的“个股残差”标签。

### 账户归因 account_other

account_other 是具体账户账本中的其他项，可能含交易成本、现金、头寸或归因方法留下的部分。其精确定义依赖账本合同。它不是金融回归残差，也不是潜残差，不能整体当成残差网络的 alpha 训练目标。

### 是否必须保留或预测

完整收益或账户分解需要保留未解释项以证明守恒；这不意味着模型必须启用残差预测器，更不意味着必须启用 DDPM。残差可以为零、可以是不可预测噪声，也可以有非零波动但条件均值为零。以上都是允许出现的结果，不得为了得到正结果而删除零残差基准、增加容量或改阈值。

## 4. 训练、预测与残差验收的不同对象

论文基准实现使用重建、潜动力和扩散损失的联合目标。训练中把真实残差加噪后再估计噪声，是有效的训练方法；其中一步反解得到的残差接触了真实目标，只是 teacher-forced 去噪诊断，不能当作正式历史预测。

| 评价对象 | 必需证据 | 不能代替它的量 |
|---|---|---|
| 条件均值预测，例如 MSE 训练的 MLP | 历史输入、同支持成熟目标、预测误差及零残差基准；同时报告股票输出误差或排序增量 | MLP 输出幅度必须接近真实残差幅度 |
| 条件分布预测，例如 DDPM | 历史输入的完整采样路径、训练终端与采样先验兼容、分位覆盖及尾部校准；适用时使用预先声明的分布评分 | noisy(true residual) 的一步去噪、只比较边际能量 |
| 跨模型金融增量 | 同任务、同目标、同可用信息、同股票与日期支持、同解码输出尺度，并登记尝试次数 | 独立训练 arm 的潜能量或矩阵距离直接相比 |
| 实现与数值有效性 | 有限值、正确维度、因果时钟、来源身份、可重现性 | 预测分数变好或账户赚钱 |

若 \(E[R\mid\mathcal I_t]=0\)，均值预测器输出零可以是平方误差下的正确答案，而分布抽样仍有非零能量。因此不能把均值幅度门套在 MLP 上；接近零的 MLP 输出既不自动失败，也不自动通过，必须检查同支持的误差证据。DDPM 的幅度诊断也不足以证明分布校准。

若使用多次 DDPM 抽样估计收益条件均值，应逐样本解码后再平均：\(M^{-1}\sum_m D(K_sZ+R^{(m)})\)。非线性 decoder 下，这一般不等于先平均潜残差再解码。

旧训练健康证书中的 gate 区间、算子占用率、残差能量比等数值门，属于特定历史协议或诊断，不是数学必要条件或当前选股晋级定理。健康、完整证书和哈希匹配只能证明所检查的有限范围；不能代签预测效力、用户金融意图或账户成功。

正式残差证书必须绑定当前消费任务、checkpoint、共同支持、序列长度、潜维度、算子容量、种子、训练年与验证年；消费端重新核对其来源和摘要。来自其他任务、其他支持的完整证书也不能移植。缺少历史预测证据时保持未获验收，不能把报告命令成功、诊断数据存在或旧 `passed` 字段当成晋级依据。

## 5. 决策时钟、标签和证据身份

所有进入时刻 t 的特征、收益历史、条件、股票池、行业归属、市值、缩放参数和缺失处理，必须在 t 的信息集中可得。使用上一自然月条件时，需要完整计算窗和实际可用时刻，不是只把字段名称改成“上一月”。14:30 或 14:45 的决策不能使用当天官方收盘以后才有的数据，日线也不能直接充当更早时刻的真实观测或成交。

向前 H 日收益标签只有在该区间终点以及数据发布延迟之后才成熟。把标签行日期移到 t-1 不会使尚未实现的标签变成历史收益。训练、验证、历史收益编码及重叠目标的切分，都必须检查真实标签端点；训练边界、purge/隔离规则和滚动缩放只能使用已允许材料。

模型潜状态的一步转移、最终预测期限和评价收益期限必须明确对应。历史月频 adapter 的一步输出不能未经证明直接解释为未来 20 日收益。QFQ 信号价格也不能被当作 raw/PIT 成交价格。

数据区间继续遵守原声明：2007–2008 为预热，2009–2025 为研究材料，2026+ 不得下载或补造；2018–2025 已消费，`fresh_oos=false`。用户补齐 2023、2024 日线只改变文件可用性，不重置证据消费状态。

## 6. Stage4 能回答什么，以及当前阻断

旧 Stage4 对象是：以前一自然月条件分组，比较随后一个月既定持仓的已实现 linked-log 因子贡献。它是条件关联归因，不能直接回答“新增条件提高未来个股预测 IC 吗”。既有持仓选择、时段和共同风险均会影响归因，贡献正负也不能直接决定特征 gate 方向或金融因子权重。

正式统计单位应在 `(data_role, decision_clock, period)` 唯一。旧已消费面板每个时钟有 98 行而只有 96 个月，2018-01 和 2021-01 重复；较早行与较晚行的组件覆盖不同。因此旧“Stage4 已完成、只等用户金融签字”的状态失效，不能让用户替数据缺陷签字。

修复必须追溯组件账及输入身份，先证明覆盖、月度唯一性和 linked-log 归因守恒，再产生新版本。不得 `drop_duplicates`、取第一行、按结果选一行或重新盖章旧结果。原文件及摘要保持冻结；上游来源缺失时报告缺口，不虚构根因已经闭合。正确拒绝此面板是现行基础设施应通过的行为，旧面板本身不会因此变成正确证据。

下一轮若评价条件预测效力，需要独立冻结总收益或金融残差目标、条件与无条件基准、共同支持、时间依赖处理和尝试分母。相近的两个时钟不自动构成独立重复验证。任何历史差异都不保证样本外 IC、成本后收益或正结果。

实现核对范围包括 [论文模型](../../src/factor_lab/factor_rotation/reaka_paper_v1.py) 的 `_encode_and_gate`、`_transition`、`training_objective`、`forecast`，以及 [OT1](../../src/factor_lab/factor_rotation/orthogonal_index_timing_transport_ot1_v1.py) 的含截距历史拟合及下一有效区间残差。现行 [金融残差参考计算器](../../src/factor_lab/factor_rotation/reaka_financial_residual.py) 显式检查同收益口径、同区间、系数先前冻结和标签成熟时刻；它仅接受小数形式简单收益、同币种及明确的单个行业序列，行业向量应另行声明后继计算接口。参考计算器验证调用者提供的身份、时钟与算术，不自行证明外部数据或系数拟合的 PIT 来源，也不启动系数拟合或策略训练。详细历史发现及证据限制保留在 [接管审计](reaka_foundation_audit_20260905.md)。原论文仅限已授权内部研究，不公开重新分发。
