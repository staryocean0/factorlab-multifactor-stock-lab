# REAKA P6.3 盘中 K1/r0 输入与参数性能白皮书

## 目的与边界

P6.3把P6.2已验收的14:30和14:45 OT1--OT3材料装配为可被纽结载体
消费的固定输入，并关闭训练前的数学、参数和运行时门。本步只能物化
输入、做无目标值的数值预检和实例化22项参数；不得进行正式拟合、生成
股票分数、运行账户或改动生产指针。

## 不可变身份

- 两个时钟独立：14:30与14:45不混合拟合、归一化或选参；
- `D5-H20-R5`，10个H20端点组成200交易日窗口；
- 一个固定Koopman算子（K1），精确零残差（r0）；
- 每只股只读自己所在的五折cross-fit variant；
- 输入71维：14个状态、14个状态mask、14个暴露、14个可靠性、14个
  暴露mask和1个D5暴露年龄；
- 量价、LAT、oracle、未来target都不得进入71维特征。

## 样本与时序

inference rows只由历史epsilon完整性和当期暴露support决定，不读未来
epsilon数值、不读入场成交结果。`labelled_row_indices`只记录标签可用性，
不能反过来筛除inference universe。D5四相位以2008-12-01全局锚点计算，
不能随数据起点重置。

2009--2016只用于无目标值归一化、输入有效秩、状态时标、DMD初始化和
LR/梯度健康预检。2017--2020在P6.3不用于选参。所有2009--2020仍是
已消费开发材料，不是fresh OOS。

## 兼容和参数门

兼容证书必须报告 `Delta_x=Delta_y=H=20`、`L=10`、`W=200`、D5决策/
换仓、四相位重叠推断、输入有效秩、状态时标和时间有效样本。
容量根只能从冻结的 `d8-h8 / d16-h16 / d16-h32`中按有效秩删减，不能读
收益结果扩容。

22项当前参数必须全部显式实例化。LR按小到大的冻结网格做同一
training-prefix batch的连续梯度健康检查，只能选首个不健康点前最大的
健康点；若边界右截断必须阻断。未剪裁梯度必须有限。

## CPU/ROCm

以同一初始权重和同一batch比较CPU与ROCm。两后端预热后交替执行5个计时块，
每块4次完整负载，以中位数判定。ROCm只有在loss、score和排名对齐且至少比
CPU快10%时才能入选；否则选CPU。ROCm不可用不是阻断项，但必须如实记录。

## 停止点

只有formal/isolated两个时钟输入逐字节一致、兼容证书通过、LR边界闭合、
CPU/ROCm回执通过、22项参数无缺失且源闭包无漂移时，P6.3才可关闭。
关闭后仍必须等用户checkpoint，不自动进入P6.4正式K1/r0训练。
