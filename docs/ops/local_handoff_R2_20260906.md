### B. P6.1：分钟观测、成交取价及收益标签

核对 calendar/symbols/decision_positions 的唯一性、顺序、shape和坐标连接；两个时钟分别检查。原实现 `HORIZON_DAYS=20`、`SEQUENCE_POINTS=10`、决策间隔为5个日历轴交易位置，这些是复现对象的配置，不是未来所有研究的强制参数。

从 lineage 定位实际分钟源、数据版本与时间戳约定；证明决策 close 对应的bar在决策时已经结束且数据可得。entry 是决策后原规则选中的首个open，而不是当日收盘或信号用前复权价格。有限正价格并不自动证明停牌、涨跌停、无成交等情况下的交易可执行性：分别报告“价源/时间匹配”和“成交可执行性是否核验”，后者必要时留给账户层，不能混为一项通过。

按原公式重算并比较：

```text
history[t] = decision_close[t] / decision_close[t-20] - 1
future[t]  = entry_open[t+20] / entry_open[t] - 1
```

t 是原 calendar 的交易位置，不是自然日。记录真实端点及取价分钟。复权/分红/拆并股处理以原合同和消费用途核对；纯raw价格收益可作为被声明的研究对象，但不能未经证明等同投资者总收益或真实账户收益，也不能静默替换为前复权序列使误差消失。

报告原数组与重算数组的有限值掩码、缺失差异、最大/分位误差、异常坐标、实际覆盖范围。未成熟未来标签保持缺失，不得据未来标签是否存在剔除本来有效的推断坐标。核查 inference_rows 与 evaluation_row_indices 的这种分离。

### C. OT1：因子基底、暴露冻结与金融 epsilon 算术

按真实生成顺序复核股票/行业成分、权重、fold、基底正交化及截距约定。不要用一个“数学上看起来相近”的联合回归替换原来的顺序残差化。若原实现使用股票位置分fold，检查其 symbols 轴身份及重排影响，不凭同样的股票集合就假定fold相同。

将原暴露表与对应时钟、适用日期、行业基底和cross-fit变体精确连接，独立计算 `epsilon = stock_return - intercept - factor_returns @ betas`，分别比较 history 与 future 原面。检查重复连接、漏连、未来补齐、失效系数被静默前填和不可用行掩码；报告暴露重拟合或运用的确切区间。

**历史输入与未来标签分开审计。** 向前收益残差的系数和预测输入必须在其预测/入场时点可得；作为当前输入的向后历史残差，则按它实际生成与被消费的时点判断。不能机械要求向后20日残差的系数一定在该20日期间起点以前冻结，除非原合同确有此定义；真正要排除的是在消费时仍未知的信息、后来的拟合结果或标签被回填为历史可得。

原源码的120位置历史窗、fit_end_date、effective_timestamp和uses_future字段都只提供线索。沿参与拟合的每个收益端点、成员生效/发布时间、行业分类和变换参数检查真正的数据时钟；发现合同与实现不同，分别报告哪一条不一致，不自动改原合同。

## 7. 证据和验收：按断言，不按“都绿了”

每项检查至少记录检查ID、时钟、对象及版本、覆盖区间/股票或坐标数、实际计算/对照、结果、异常数量和位置、未检范围。可以放在同一报告的表格里，不强制生成一堆机器合同。

数值比较先声明依据dtype和计算过程选择的容差，形式可用 `abs(a-b) <= atol + rtol*abs(reference)`；不得看到差异后放宽阈值。文件字节身份比较、数组数值比较、排序/交易路径比较是不同断言，不能互相替代。

先选择有解释力的边界切片：两个时钟、首次可用历史、拟合/决策切换、缺失或停牌、除权/行业变更、样本尾端标签不成熟等。必要时按任务实际支持扩到全量；允许分批、向量化和并行，不强制硬件/固定样本数/逐年人工会话。选择在结果前记录，失败也记录。切片验证不能写成全量PIT通过。
