# REAKA 输入与配置数学兼容性白皮书

> 版本：V1.0
> 生效日期：2026-08-16
> 责任项：`bd://fl-afrb5`
> 适用范围：REAKA 的输入建设、论文复现、项目适配、逐层归因与 battle
> 当前权限：只规定研究合同，不授予调参、策略替换或生产权

## 0. 一句话结论

REAKA 的输入没有一张“每个值必须等于多少”的永久参数表。正确做法是先声明数据频率、预测期限、回看长度、信号更新速度、状态持续时间、有效特征秩、潜空间维度、算子数量、每状态样本量和残差尺度，再验证这些量之间是否匹配。

> **2026-08-25参数治理升级：**所有论文明确、可推导、可测量、项目政策和未决参数现由[`REAKA论文参数治理白皮书`](reaka_paper_parameter_governance_whitepaper.md)与[`机器目录`](reaka_paper_parameter_catalog@1.1.json)逐项管理。22个表面阻断经约束闭包压缩为3个真正自由根；类构造函数默认值没有参数权威，自由度门或逐次运行实例化门未清零时训练必须阻断。

本文只设三类规则：

1. **硬门**：违反 PIT、时钟、标签可见性、身份或共同支持集时直接停止；
2. **关系诊断**：通过无量纲比例、有效样本和尺度校准判断是否匹配，不因一个经验阈值一票否决；
3. **经验选择**：潜维、算子数、扩散步数等只能在预注册的有界候选族中比较，不冒充论文定律。

## 1. 论文的数学边界

对标的 ICASSP 2026 论文直接输入两条个股序列：

- 历史收益 `y_1:T`；
- 历史特征 `X_1:T`。

模型内部学习 gate、潜状态 `Z`、样本对算子的归属、具体 Koopman 矩阵 `K_i`、残差分布和预测分数。人工不得把当期潜状态 ID、operator ID、已知未来的因子效力或真实残差当作普通特征填回模型。

论文实验给定了沪深300、Qlib Alpha158、日频、10个交易日窗口、2010--2017 训练、2018 验证、2019--2020 测试和 Top30。但它没有公布潜维、算子数、optimizer、epoch、batch、Gumbel 退火、扩散步数、噪声日程和完整交易成本。这些只能写成“实现者选择”，不得写成“论文参数”。

## 2. 兼容证书的基本量

每次训练前必须冻结下列量，并保留原始单位：

| 记号 | 含义 | 不能省略的说明 |
|---|---|---|
| `Delta_x` | 特征真实更新/采样间隔 | 日、周、月或事件驱动；不能只写数组行距 |
| `Delta_y` | 历史收益序列的间隔 | 收益是一步增量、重叠持有期收益还是事件收益 |
| `H` | 预测/持有期限 | 标签起止、入退场价格及 `available_at` |
| `L` | 序列观测点数 | 必须同时报告物理回看长度 `W=L*Delta` |
| `tau_x` | 特征的经验半衰期/刷新时间 | 由滞后 IC、自相关或机制给出，不由列名猜测 |
| `tau_s` | 潜在动力状态的持续时间 | 由训练前可观测线索或内层状态诊断估计 |
| `r_eff` | 特征有效秩 | 用特征协方差谱的 participation ratio 或等价方法 |
| `d` | 潜空间维度 | 项目容量，不是输入因子数 |
| `K` | 允许的 Koopman 算子数 | 项目只给容量，矩阵和归属由模型学 |
| `n_eff` | 扣除重叠标签、自相关和簇群后的有效样本 | 不得用原始行数冒充 |
| `n_k_eff` | 第 `k` 个算子的有效转移数 | 软归属按权重计数，不只看 argmax 占用 |
| `E_R_true/E_R_pred` | 真实/生成潜残差能量 | 同时报告中位数、高分位和状态内分布 |

## 3. 三类规则

### 3.1 只对因果性和可比性设硬门

以下任一发生就停止，不用更好收益豁免：

1. 特征、掩码、跟随权重或股票池使用决策时不可见信息；
2. 历史收益在其退场日之前被输入下一个样本；
3. 训练缩放、缺失填补、特征挑选或状态命名读了外层答案；
4. 比较两个模块时日期、股票、标签、成本或组合规则的共同支持集不一致；
5. 只报原始样本量，却不报重叠持有期和序列相关后的 `n_eff`；
6. 使用潜状态 ID、operator ID、当期真实残差或未来因子效力作为外部 alpha。

### 3.2 尺度匹配是诊断，不是绝对禁令

时间兼容证书至少计算：

`q_h = H / Delta_x`，`q_w = W / H`，`q_x = tau_x / Delta_x`，`q_s = tau_s / Delta_x`。

- `q_h < 1` 不表示数学上不能预测；它表示信号更新慢于目标期限，因此只能声称“这个月度决策点对未来短窗有截面预测力”，不能声称“模型在短窗内识别了状态转折”。
- `q_h` 较大时，慢因子预测长持有期可以合理，但必须证明 `tau_x` 足以支撑 `H`，并对重叠标签调整有效样本、bootstrap block 和年化。
- `q_w` 太小时看不到完整的目标尺度；太大时可能把多个已变化的动力混为一个状态。不设通用上下限，必须报告邻域窗口下状态占用、转移和排序稳定性。
- `q_s <= 1` 意味着状态持续时间不长于采样间隔，当前频率不能识别状态转换；此时要么提高采样频率，要么降级为静态截面模型。

### 3.3 容量是相对样本和有效秩的选择

1. `d` 必须与 `r_eff`、`n_eff` 和重构/预测任务匹配。不要机械要求 `d<F`；应检查潜维参与率、方差、扰动稳定和扩容后的实际增益。
2. 每个无结构的 `d x d` Koopman 矩阵约有 `d^2` 个自由度。因此必须报告 `n_k_eff / d^2`、矩阵条件数和扰动后稳定性。本文不规定一个永久比值，但没有这三项就不允许声称算子可识别。
3. 单算子占优不自动等于塌缩；当其他算子在独立种子、时间折和小扰动中持续无区分信息时，应允许降级到 `K=1`。同样，不得用“占用必须平均”的正则伪造多状态。
4. `K` 的合法价值来自冻结前缀中的预测误差、排序、矩阵差异、状态持续和多种子稳定的共同改善，不来自算子数本身。

## 4. 残差和扩散的尺度约束

论文中的真实潜残差是 `R=Z+ - K_s Z`，不是价格残差，也不是人工供给的因子。扩散通道必须满足：

1. **训练尺度校准**：噪声日程要以训练前缀中 `R` 的方差、分位和尾部为参照，不直接照搬图像 DDPM 的 beta 范围；
2. **生成尺度校准**：报告 `||R_pred||/||R_true||`、分维方差比、高分位比和状态内比较。只要生成残差系统性淹没主动力或缩成近零，就是尺度故障，不用收益解释；
3. **简单参照**：扩散必须同时超过零残差和同容量 MLP/线性残差，并且改善不能只由某个尾部时段提供；
4. **采样收敛**：推理 draw 数由跨 draw 的分数排序相关、TopK 成员稳定和 Monte Carlo 标准误差决定，不固定为 1 或 4；
5. **从简到繁**：零残差→线性/MLP→扩散的每一步都要重训和保留同权重路径归因。不得用后一层掩盖前一层的输入或算子故障。

## 5. 损失和训练约束

论文写为 `L_rec + L_koop + L_diff`，但三项 MSE 的数值单位和梯度尺度可能不同。“等权相加”只是公式结构，不能免除尺度检查。

每次运行必须保存：

- 各损失的首值、最优值、末值和单独梯度范数；
- 各损失对共享编码器参数的梯度夹角，区分互助与对抗；
- 原始损失和标准化/加权损失，以及权重产生方法；
- 去掉每一项项目扩展损失的重训消融。

目标对齐、状态占用、状态置信、潜方差、稳定性或排序损失都属于 FactorLab 扩展。每一项必须有独立机制、单独权重、重训消融和新 fingerprint。不允许一边改五个损失，一边将收益差归因给某一个模块。

## 6. 特征、状态线索、掩码与跟随权重

1. 特征和可观测状态线索都是 `X`，必须 PIT、使用训练前缀缩放，并声明是个股截面信息还是全市场广播信息。
2. 变化很慢的月/季度基本面值可以和日频价量共存，但必须保留“未更新”和“缺失”的语义；不得通过插值伪造日频新信息。
3. 空间掩码只能由决策时可观测的个股描述量构造；掩码内外必须报告覆盖、样本数、成本和全池参照。
4. 跟随权重只能用当前时点之前已实现的因子效力；其回看长度必须与效力半衰期匹配，并设置历史不足时的中性退化。
5. 原始因子只输入一次。掩码、跟随权重和状态交互是可审计变换，不是复制一份 alpha 再投票。

## 7. 目标、调仓和组合必须对齐

1. `H` 是模型考题，调仓周期是决策频率，持有期是组合实现；三者可以不相等，但必须明确说明重叠仓位和成本如何结算。
2. 月频因子预测10日收益不是数学上禁止，但它不具备10日内更新状态的能力；除非增加日频载体，否则只按月度决策点的短窗截面信号验收。
3. 月频因子预测100日可以合理，但要证明因子半衰期和稳定性覆盖目标期，并对高度重叠的100日标签使用 block/HAC 类推断，不把每月标签当独立样本。
4. TopK、Top/Bottom 比例、权重、调仓、停牌/涨跌停、冲击成本和容量都是外层输入。改变它们就是改变策略，不是只换一个显示指标。

## 8. 共同支持集是逐层归因的前提

任何“加了一层收益变化多少”的报告，必须先对每个对比形成：

`C = date ∩ symbol ∩ target ∩ tradability ∩ cost ∩ portfolio_rule`。

必须同时报告：

- 父层原始月数/样本数；
- 子层原始月数/样本数；
- 交集月数/样本数和丢失原因；
- 只在 `C` 上计算的双方收益、IC、回撤、换手和逐年增量。

原始支持集不同时，可以另外报告各自完整面指标，但标题必须写“非配对诊断”，不得作模块胜负。

## 9. V2.4 回溯审计的纠偏

V2.4 保留为“FactorLab 月频适配诊断”，不再解释为论文日频版数值复现：

1. 论文用日频 Alpha158、10个交易日和下一期收益；V2.4 用月频 106 因子、10个月度观测和20交易日收益。这是新问题，不是小参数变更。
2. V2.4 的 `d=16`、`K=4`、24 epoch、6扩散步、4 draw、beta 日程、优化器、早停和四项附加损失均为项目默认，不是作者参数。
3. 完整扩散残差的抽样能量约 `1.047`，MLP 残差约 `0.0006`；两者尺度相差约1700倍。在未对 `R_true` 完成能量和尾部校准前，扩散失败首先裁决为 `residual_scale_measurement_gap`，不裁决为论文框架失效。
4. 原报告透明 Rank 有 72 个月，神经层只有 40 个月。同一 40 个月/同股票坐标上，透明 Rank 年化多空为 `+11.44%`，不是原完整面的 `+8.83%`。原方向判断没有反转，但旧表不再拥有“严格同口径 battle”权限。
5. 同一 40 个月支持集上，编码器/Koopman/MLP 残差/完整扩散分别为 `+1.48%/-1.04%/+6.76%/-4.76%`。去掉 gate 为 `-5.61%`，说明 gate 约带来 `+0.85pp`；去掉 AKS 为 `-2.23%`，说明当前 AKS 约带来 `-2.53pp`。旧白皮书中“AKS 相对缺失版有帮助”的文字被本文替代。

因此 V2.4 仍能证明输入已进入计算图、MLP 残差是有用反例材料、当前扩散存在明显尺度故障；它不能证明完整论文 REAKA 在 A 股失效。

## 10. 未来运行的必备产物

当前可执行实现为[`REAKA Stage 5 输入数学兼容证书`](reaka_stage5_input_compatibility_whitepaper.md)。它使用Stage 4的1,183张使用票生成训练前证书，并将 `n_k_eff`、残差尺度和损失梯度明确留为训练后补签义务。

任何新 REAKA 运行都必须在读取外层答案前产生 `input_compatibility_certificate`，至少包含：

- 所用参数目录的版本与digest、scope gate和未决参数清单；

- 输入身份、频率、可见时间、半衰期和有效秩；
- `Delta_x/Delta_y/H/L/W/tau_x/tau_s`及派生比例；
- `d/K/n_eff/n_k_eff/d^2`及状态可识别诊断；
- 真实残差、简单残差和扩散残差的尺度/尾部校准；
- 损失数值、梯度范数、夹角与扩展消融；
- 父层、子层和共同支持集身份；
- 硬门结果、关系诊断、待决经验配置及顾问回执。

兼容证书通过只表示“这组数据和配置值得训练”，不表示必然有收益。证书不通过时，要回到输入、尺度、容量或测量层修复，不允许跳到组合层补规则。

### 正交指数择时运输的兼容入口

`orthogonal_index_timing_transport@1.0`属于Stage4之前的透明因子构造，不是论文潜残差。市场、单一规模、行业和特异四类股票运输列必须分列通过Stage4；至少一列准入后，后继Stage5证书才读取每列真实FrequencySignature、更新间隔、半衰期、共同支持、有效秩和TransportReceipt。现有Stage5实现将宽表默认记为日频，不能据此把D5/D20/D60运输列静默登记为D1；在真正后继装配时必须重建频率感知证书。当前固定`CORE_SPATIAL_H20`不可就地加列或续checkpoint。
