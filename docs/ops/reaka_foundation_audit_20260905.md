## 1. 用户要解决的金融问题

依据本次指令和 current manifest 引用的产品、模型装配文档：

- 使用市场、大小盘、行业及后续个股信息，在市场规律变化时改善 A 股横截面选股。
- 既有产品为始终满仓的主动多头，允许主动市值、行业和风格暴露；控制暴露用于辨别机制，并不要求组合强制中性。
- 第二轮原计划加入“上一自然月 CloudRidge 趋势条件”，作用于指数、行业通道；规模暂不加该条件。
- 数学方法必须先证明对象、时钟、统计量与上述金融问题一致，然后才讨论新增因子、容量和经济效果。

因此，市场好时给所有股票相同加数，并不能改变排序。需要异质 beta、行业交互或模型学得的相对差异。全市场广播状态也不能通过复制到几千只股票，就被计为几千份独立市场状态样本。

## 2. 论文数学和项目对象的正确映射

论文第2697页 Eq7–15、第2698页 Eq16–31 给出的核心关系为：

```text
Hy = LSTM_y(y_history)
Hx = LSTM_x(X_history)
G = sigmoid(GateNet(Hx))
Z = Hy * G + Hx * (1-G)
a = SelectorNet(Z, Hy)
Ks = sum_i alpha_i Ki       # 训练：Gumbel-Softmax
Ks = K[argmax(a)]           # 推理：索引 codebook
Zhat_next = Ks Z
R_latent = Z_next - Zhat_next
Ztilde_next = Zhat_next + Rhat_latent(Z)
score = Decoder(Ztilde_next) 的最后一期输出
L = L_rec + L_koop + L_diff
```

| 对象 | 正确含义 | 不成立的替代解释 |
|---|---|---|
| 市场、规模、行业因子 | 收益解释变量或有金融含义的预测输入 | 三个 Koopman 矩阵 |
| S_obs | 决策时已可见的外部条件 | 模型必须预测的 operator 标签 |
| G | 历史收益编码与特征编码的潜维融合比例 | 市场/规模/行业投资权重 |
| Ki | 模型学习的潜空间转移矩阵 | 一个预先命名的宏观真状态 |
| N=1/2/3 容量实验 | 单算子、双算子、三算子候选 | 三类因子依次进模型 |
| N_effective | 给定任务、样本和训练协议下被支持的有效容量 | 永久不变的市场状态总数 |
| R_latent | 潜动力预测剩余 | 个股收益减三类金融收益 |
| epsilon_return | 指定金融回归模型的收益剩余 | 已证明可交易的纯 alpha |
| account_other | 账户归因其他项，可能含成本、现金、头寸等 | 可以整体交给残差网络的个股信号 |

**gate 的方向尤其容易误读：G 变大增加 Hy 的占比，而非直接增加市场因子权重。** 当前论文实现这一点是正确的。条件应作为 Hx 的上下文或预注册交互进入，不应根据 Stage4 的贡献符号手调 G。

论文支持按时间步选择算子，但股票级 selector 不会自然等同于一个全市场统一的 regime。若金融目标必须是统一市场动力，还需显式定义共享层；不能只给每只股票的隐状态贴同一个名字。

## 3. 残差如何算，是否必须，是否必然有效

金融收益分解可以在同一收益口径下定义为：

```text
epsilon_return(i,d) =
    r(i,d) - alpha(i,t) - beta_market(i,t) F_market(d)
           - beta_size(i,t) F_size(d) - beta_industry(i,t)' F_industry(d)
```

其中 t 是系数冻结时刻，严格先于 d。已实现因子收益 F(d) 与股票收益 r(i,d) 都只有实现后才能用于计算历史剩余。预测未来股票收益时，不能把未来真实 F 或 epsilon 填回输入。市场、规模、行业需明确是否联合估计、共线性处理、行业约束、加权方式和股票池；顺序残差化会受顺序影响。

OT1 代码已有“先前周度系数 + 后续已实现收益”的金融残差方向。它仍包含遗漏共同风险、系数误差和噪声；样本内 OLS 正交不保证下一段正交。不能把“已纳入三类因子”解释为“剩下已知全是个股独立 alpha”。

论文的 R_latent 则依赖编码器与 Ks；训练可计算真实 R，推理只能从历史条件估计或采样。两种残差应独立命名、存储、可见性校验和验收。

残差**不必须非零、不必须可预测、更不必须赚钱**。线性系统或有限维不变子空间可使 R=0；即使 R 不为零，条件均值也可能为零。若 R|Z 服从零均值分布，最优平方误差残差预测为0，而正确分布样本仍有非零能量。旧白皮书将“生成残差近零”直接判尺度故障，或用 DDPM/MLP 约1700倍能量差单独判故障，均过强。

必须分别检查：

1. 条件均值/方向预测及对股票输出误差、排序的增量；
2. 条件分布的方差、分位覆盖与尾部校准；
3. 仅用历史信息的真实 forecast 路径，不能用接触真实残差的一步去噪替代；
4. 零残差、简单残差和扩散的同任务比较。

多次扩散抽样应每次先经非线性 decoder 解码，再平均输出；现实现此处正确。独立训练 arm 的潜坐标可能不同，不能直接把绝对潜能量横比后宣布胜负。

## 4. K1、K2 和可辨识性

原论文里的 K1、K2 是矩阵下标；项目口语里的“K1 实验、K2 实验”常指 N=1、N=2 的容量候选，报告应写清。

当前单算子支持主要在 Stage6 的专门适配中，不能把基础 ReakaPaperConfig 的旧默认值当后继配置。容量上限是结果前冻结的研究预算；矩阵和归属由训练学习，有效容量由数据证据判断。外部状态类别数和持股 TopK 均不能决定 N。

潜坐标变换 Z'=AZ、Ki'=AKiA^-1、R'=AR 可保持最终预测；operator 标签也能置换。不同 Ki 若只在数据未占据方向上不同，不算识别到不同动力。应在共同观测支持上检查算子作用、decoder 输出、滚动稳定和跨折标签对齐。

项目“逐级 K，停止后才看残差”是为了可归因与有界搜索的政策，与论文端到端联合训练不等价。K2 未通过不构成 K3 必失败的数学证明。还必须区分：

- 数据泄漏、非有限值、时钟错误等基础有效性失败：后层不能掩盖；
- K-only 没有经济增量：不推出 K+R 必不可能有效。

本轮不改变已冻结搜索政策，也不据这些论点开启新候选。未来若比较完整联合训练，需要独立预注册身份和预算。

## 6. 对当前五个机制的顾问判断

这些都是未签署的意见；旧对照数值还受重复月缺陷影响。

| 假设 | 顾问判断 |
|---|---|
| 上一月上涨，增强指数 | 可保留为探索问题；开发年度支持弱，不足固定增强 |
| 上一月下跌，减弱指数 | 原表在两段历史均与预期相反，不支持强制减弱；也不能据此翻向调参 |
| 上一月上涨，增强行业 | 开发与对照不稳定，机制尚未确立 |
| 上一月横盘，增强行业 | 跨段反转，不支持固定增强，也不能挑一个时钟作为通过 |
| 上一月下跌，减弱行业 | 跨段反转，不支持固定减弱 |

Stage4 当前统计是“前一月条件关联下一月旧持仓实现贡献”，不是“当下市场状态的解释”，更不是“该条件改善未来个股排序”。五个分母登记不等于已完成多重校正；两相近时钟也不是两份独立证据。应另行冻结预测效力的估计对象、共同支持、重叠处理和不确定性检验。

## 7. 尚未执行的后继装配草案

基础数据和重复月问题处理后，可准备如下输入方案，不在本轮执行：

- 因子主通道保留唯一身份；S_obs 作为有 availability 的上下文，并为指数、行业分别声明交互；规模保持无新增条件交互。
- 不强制某个条件对应某个 operator，不规定gate或金融效力的正负方向；缺失条件使用显式mask与中性回退。
- 训练前固定收益目标、历史收益成熟时刻、预测步长、标签端点、PIT缩放、股票池及评价支持。
- 同条件比较透明因子基准、无条件模型、带条件模型；再按已批准的容量与残差协议比较。去掉条件的冻结模型诊断与从头重训消融分别报告。
- 若拟研究 epsilon_return，先声明它是预测输入、预测目标还是归因诊断；不得暗中把“预测总收益”换成“只预测残差”。
- 允许无增量、单算子获支持、零残差最好及框架不被数据支持等结果。数学有效性、预测效力和扣费账户结果分别验收。
